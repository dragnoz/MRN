# Change Log

All notable changes to the "Minecraft Resource Toolkit" extension will be documented in this file.

## [0.2.2] - 2024-05-02

### Fixed
- Fixed icon path handling in tree providers (using proper Uri objects)
- Updated documentation with detailed installation instructions
- Improved example files with more comprehensive code comments

## [0.2.1] - 2024-05-02

### Added
- Tag support for code snippets
- Full scoreboard objective tracker with usage count
- Jump-to-location functionality for scoreboard locations
- Search functionality for snippets
- Custom icons for light and dark themes

### Changed
- Improved organization of snippets by category and tags
- Enhanced UI for better discoverability
- Updated documentation with installation and usage instructions

### Fixed
- File path resolution for cross-platform compatibility
- Storage mechanism for persistence across sessions

## [0.2.0] - 2024-04-15

### Added
- Initial release of the extension
- Basic snippet repository
- Simple scoreboard objective tracking
- Explorer sidebar integration
